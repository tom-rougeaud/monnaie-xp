# Monnaie XP (version 2.0.0)

Jeu pédagogique pour s’entraîner à rendre la monnaie, avec de vraies images de pièces et de billets à l’échelle réelle.

- Auteur : Tom Rougeaud
- Réalisé avec l’aide de l’IA : Claude Sonnet 5.5 (Anthropic)
- Licence : CC BY-NC 4.0 (https://creativecommons.org/licenses/by-nc/4.0/deed.fr)

## Fichiers
- `index.html` : l’appli complète (un seul fichier, fonctionne hors ligne)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` : installation sur l’écran d’accueil (PWA)
- `.nojekyll` : à garder dans le dépôt GitHub Pages

## Publier sur GitHub Pages
Déposer ces fichiers à la racine du dépôt (ou d’un sous-dossier), activer Pages, puis ouvrir l’adresse du site.
À chaque nouvelle version : changer le numéro dans « À propos » et le nom du cache dans `sw.js`.

## Données
Aucune donnée ne quitte l’appareil (voir la page « Confidentialité » dans l’appli). Aucun CDN, aucune police distante.
